Python ABL -- Case Study Programs
Project Overview
This project contains ten Python case studies based on everyday
academic, financial, travel, and business scenarios. Each case study
presents a problem statement, objectives, assumptions, algorithm,
flowchart, pseudocode, Python source code, test cases, output, and
conclusion.

Requirements
Python 3

A text editor or Python IDE (for example, IDLE or Visual Studio
Code)

The programs use standard Python features such as: - Variables and user
input - Arithmetic operations - Conditional statements (if, elif,
else) - Loops - Lists, tuples, and dictionaries - Sorting and built-in
functions - Basic mathematical calculations

How to Run
Install Python 3 on your computer.

Open the Python source code for the case study you want to run.

Save the code in a file with a .py extension.

Open a terminal or command prompt in the folder containing the file.

Run:

python filename.py
Enter the values requested by the program and view the result.

Replace filename.py with the actual name of your Python file.

Testing
Each case study includes test scenarios to check its calculations and
decision-making. Run each program with the sample inputs in the project
document and compare the displayed results with the expected results.
Also try boundary values and invalid inputs where the program includes
validation.

Learning Outcomes
By completing these case studies, students practise: - Applying Python
to practical problem-solving situations. - Designing algorithms and
pseudocode before coding. - Using conditions and loops to process
different cases. - Performing calculations involving bills, salaries,
fares, costs, and budgets. - Testing programs with different inputs and
interpreting outputs.

Notes
The calculations and policy rules are based on the assumptions
stated in each case study.

Rates, thresholds, concessions, and sample values are educational
examples from the project document; they should not be treated as
current official tariffs or policies.

Some case studies describe features in their problem statements that
may be broader than the supplied sample code. Refer to the actual
source code when running a program.

Conclusion
The Python ABL project demonstrates how Python programming concepts can
be applied to solve a variety of practical problems. The ten case
studies strengthen problem-solving, logical thinking, coding, and
testing skills.
